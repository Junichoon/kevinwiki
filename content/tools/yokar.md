# 優可線上看 YOKAR

> 台灣個人開發的追番網站，整合 YouTube 官方頻道的動漫、電影、戲劇，免登入可看。

- 網址：https://yokar.net/
- 開發者：陳名嘉；2026-11 上線，測試中
- 片源：YouTube 官方頻道嵌入（Muse 木棉花、Ani-One Asia 等），**網站本身不放影片**
- 規模（2026-11）：約 731 部動漫、2,159 部電影
- 篩選：類型、地區、作品形式、年份、連載狀態

| 功能 | 需登入 |
|---|---|
| 瀏覽、搜尋、播放 | 否 |
| 訂閱追番、同步觀看紀錄 | 是（Email / Google）|
| 新集數通知（Email 約 30 分鐘彙整 / Discord）| 是 |
| 留言、評分 | 是 |

## 注意
- 首頁「正版授權」= 片源是官方頻道；網站本身**沒有**授權
- 官方頻道下架或關閉嵌入，該集就會消失；有地區限制與 YouTube 廣告
- 檢查原始碼未見彈窗廣告聯播網（不同於一般盜版站）
- 分享連結後的 `?fbclid=...` 是 FB 追蹤碼，可刪
